✅ Solution: toObservable() + debounce

   // Convert Signal to Observable
   search$ = toObservable(this.search);
   
   // Apply RxJS operators to debounce
   searchResult = toSignal(
     this.search$.pipe(
       debounceTime(500),        // Wait 500ms after typing stops
       switchMap(q => this.searchAPI(q)) // Cancel previous requests
     )
   );

Result: Only 1 API call after user stops typing! 🎉

💡 Key Benefits

  • toObservable(): Use RxJS operators (debounce, switchMap, etc.) with Signals
  • toSignal(): Automatic cleanup, no manual unsubscribe, reactive templates
  • Best of both worlds: Signal simplicity + Observable power
